# 视觉方向样稿（3 选 1）

用同一份"高级销售经理"简历内容，做了三种纸面语言，方便对比选择。

| 文件 | 风格 | 一句话 |
|---|---|---|
| `samples/a-warm-serif.html` | 暖纸衬线 · 编辑感 | 暖白纸、宋体标题、陶土红单点强调、编号章节 |
| `samples/b-cool-swiss.html` | 冷灰极简 · 瑞士网格 | 纯白、左侧栏目标签、唯一彩色是职位行 |
| `samples/c-deep-green.html` | 深墨绿 · 商务 | 深色头图 + 菱形章节锚点，稳重有识别度 |

- 截图：`shots/*.png`（794×1123，2x）
- 对比图：`compare.html`

## 说明

- 三份都是**独立 HTML 样稿**，不依赖项目构建，用来定方向，不是最终组件。
- 字体全部使用 macOS 系统字体（Songti SC / PingFang SC），符合现有 CSP `font-src 'self'`，不需要引入外部字体。
- 选定后，落地方案是：把该稿的颜色/字号/间距抽成 CSS 变量 → 替换 `src/index.css` 的 `.editor-app` 令牌 → 重做 `LivePreview` 的纸面结构 → 同步 `exportWord.ts` 与 PDF 导出。
